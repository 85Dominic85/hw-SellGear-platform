1. QUÉ ES ESTE PROYECTO
--------------------------------------------------------------------------------

Plataforma web interna para la empresa Hardware que centraliza la gestión de
pedidos/operaciones que actualmente se registran en un Google Sheet llamado
"MainOperation".

PROBLEMA QUE RESUELVE:
  - La información llegaba por Slack/DMs/reuniones 1:1 sin estructura.
  - Errores frecuentes por datos incompletos o mal introducidos.
  - Dificultad para saber el estado real de un pedido rápidamente.
  - El Google Sheet se vuelve insostenible a medida que crece el negocio.

SOLUCIÓN:
  - Supabase como fuente de verdad (base de datos PostgreSQL).
  - Ingesta validada: Typeform → Webhook → Supabase.
  - Flujo por estados, asignación de responsables, auditoría completa.
  - Sincronización controlada hacia Google Sheets (unidireccional, Supabase → Sheets)
    mientras exista dependencia del Excel.
  - App web interna con login restringido a @qamarero.com.

3. MODELO DE DATOS (Supabase/PostgreSQL)
--------------------------------------------------------------------------------

  TABLA: orders
    - operation_id (texto único, ej: OP-2025-001)
    - customer_name, venue_name
    - purchase_type, source_department
    - amount
    - invoiced (boolean, marca si esta facturado)
    - supplier (texto, proveedor asignado)
    - bank_receipt_url
    - ae_ref (referencia ejecutivo de cuentas)
    - shipping_address
    - status (enum controlado)
    - notes
    - phone, contact_email
    - hubspot_ref, invoice_ref
    - assigned_to
    - sheet_tab, sheet_row (para referencia cruzada con Excel)

  TABLA: order_items
    - order_id (FK → orders)
    - product_name
    - qty

  TABLA: status_history (auditoría)
    - order_id, from_status, to_status
    - changed_by, changed_at, comment

  POLÍTICAS RLS: habilitadas para control de acceso por rol.
  SEED: estados predefinidos cargados vía migración.

8. CÓMO ARRANCAR EL PROYECTO EN LOCAL
--------------------------------------------------------------------------------

  cd apps/web
  npm install
  cp .env.local.example .env.local   # Rellenar variables Supabase
  npm run dev                         # http://localhost:3000

  Variables necesarias (.env.local):
    NEXT_PUBLIC_SUPABASE_URL=
    NEXT_PUBLIC_SUPABASE_ANON_KEY=
    SUPABASE_SERVICE_ROLE_KEY=       # Necesaria para crear/eliminar usuarios
    NEXT_PUBLIC_APP_URL=             # URL de la app (produccion o localhost)
    SLACK_WEBHOOK_URL=               # Opcional: webhook de Slack

  Para tests:
    npm run test
