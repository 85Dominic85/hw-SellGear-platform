# .claude

Carpeta de trabajo para **Claude Code**.

- `PROMPT_MVP.md` — Prompt recomendado para arrancar el MVP.
- `agents/` — Roles para delegar tareas (PO, integraciones, backend, UI, performance…).
- `skills/` — Procedimientos repetibles (migraciones, RLS, sync sheets, webhook, slack, emails, testing).
- `mcps/` — Documentación y plantillas para MCPs (Sheets, Slack, Gmail, Supabase).
- `commands/` — Comandos reutilizables (ej: generar tests).
